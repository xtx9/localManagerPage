Web / PWA

브라우저 중심오프라인 사용IndexedDB

Web / PWA는 브라우저에서 보편적으로 접근할 수 있게 설계된 접근형 환경입니다. 네트워크가 불안정해도 로컬 저장소 기반으로 핵심 작업을 유지하는 것이 목표입니다.

브라우저 기반으로 편리하게 작업을 점검하고, 필요한 경우 로컬 복원과 백업 전략을 함께 운영합니다.

기본 사용 흐름

  1. 1
    브라우저로 앱에 접속합니다.
  2. 2
    작업, 메모, 문서를 로컬 저장소에 보관합니다.
  3. 3
    오프라인 상태에서도 일시적으로 관리합니다.
  4. 4
    백업 또는 수동 동기화가 필요할 때 사용자가 직접 수행합니다.

장점

  • 기기 제약이 적음
  • 웹 브라우저 접근성과 오프라인 지원에 유리
  • 새 기능 전환이 빠름

주의 사항

  • 브라우저 보안 범위와 저장소 제약을 이해해야 함
  • Service Worker와 캐시 관리가 안정적으로 동작해야 함
  • 민감 정보와 사용자 인증 정보의 보관을 제한해야 함
