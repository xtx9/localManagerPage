VS Code Extension

개발용 첫 진입점 Workspace 중심 로컬 우선

VS Code 확장은 localManager의 가장 자연스러운 진입점입니다. 개발자 작업 환경과 프로젝트 컨텍스트, 문서 기록, 메모를 이어주는 역할을 맡습니다.

이 플랫폼은 코드 편집과 작업 관리를 함께 유지하며, 로컬 파일과 로컬 SQLite 데이터에 접근해 문서와 코드의 맥락을 연결합니다.

기본 사용 흐름

  1. 1
    저장소 또는 워크스페이스를 엽니다.
  2. 2
    localManager 뷰를 활성화하고 프로젝트를 선택합니다.
  3. 3
    상태, 메모, 작업, 링크를 확인하고 문맥을 연결합니다.
  4. 4
    배포, 외부 전송, 자동 실행은 승인 흐름으로 제한합니다.

장점

  • 개발자에게 가장 가까운 작업 환경에서 정보와 코드를 함께 관리
  • 문서와 코드의 맥락을 함께 유지할 수 있음
  • 워크스페이스별 실시간 연동과 기록 관리가 용이

주의 사항

  • 허용 경로와 사용자 승인 흐름을 준수해야 함
  • AI 실행이 외부로 전송하거나 과금을 유발하지 않도록 제한
  • 설계 문서와 실제 구현 상태가 일치해야 함
