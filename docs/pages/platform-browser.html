Browser Extension

보조 입력사용자 명시적 액션최소 권한

Browser Extension은 브라우저 컨텍스트에서 메모와 링크를 빠르게 남기는 보조 도구입니다. 사용자가 명시적으로 실행했을 때만 데이터를 기록하도록 설계합니다.

중요한 점은 자동 수집과 민감한 정보 저장을 허용하지 않는 것입니다. 보조 도구로만 활용해야 합니다.

기본 사용 흐름

  1. 1
    브라우저 확장을 설치하고 권한 범위를 확인합니다.
  2. 2
    현재 페이지에 대한 메모, 링크, 요약을 사용자 행동으로 저장합니다.
  3. 3
    저장된 데이터는 로컬 또는 메인 앱으로 전달해 후속 작업을 이어갑니다.
  4. 4
    민감 사항은 보관하지 않고, 명시적 동작만 기록합니다.

장점

  • 웹 컨텍스트를 빠르게 보조 기록
  • 사용자 의도 기반으로 동작
  • 메인 앱과 분리된 경량 수집 도구

주의 사항

  • 자동 수집과 민감 정보 저장 금지
  • 브라우저 보안 범위를 준수해야 함
  • 주요 앱만이 영구 저장소를 관리하도록 구성
