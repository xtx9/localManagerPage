Usage guide

앱별 사용 방법

로컬 우선 사용자 주도 동기화 안전한 AI 보조

localManager는 한 번에 하나의 앱만 있는 구조가 아니라, 같은 기본 개념을 각 플랫폼에서 다르게 표현하는 제품군입니다. 각 앱은 프로젝트, 메모, 작업, 일정, 문서를 공통 원칙에 따라 관리합니다.

핵심은 로컬 우선 저장과 명시적 동기화입니다. 자동 동기화는 기본 비활성화하고, 사용자가 직접 시작한 동기화나 백업 흐름만 허용합니다.

VS Code Extension

개발자가 가장 자주 사용하는 환경에서 프로젝트와 문서를 연결하는 최적의 입구입니다.

  1. 1
    VS Code에서 워크스페이스 또는 저장소를 엽니다.
  2. 2
    localManager 뷰와 명령을 실행해 프로젝트를 등록하거나 선택합니다.
  3. 3
    메모, 작업 항목, 문서와 코드 변경 사항을 같은 맥락에서 점검합니다.
  4. 4
    AI 제안과 문서 요약은 보조로만 사용하고, 변경과 배포는 명시적 승인 흐름으로 처리합니다.

추천 사용 사례: 코드 중심 개발, 문서와 작업 흐름 통합, 워크스페이스별 프로젝트 관리.

Windows App

장기적으로 로컬 데이터를 통합 관리하는 데스크톱 중심 앱입니다.

  1. 1
    Windows 앱을 열고 프로젝트/작업 목록을 생성합니다.
  2. 2
    메모, 일정, 문서, 파일 연결 정보를 로컬 DB에 정리합니다.
  3. 3
    작업 우선순위와 상태를 관리하고, 필요한 경우 수동 동기화 또는 백업을 실행합니다.
  4. 4
    로컬 보관된 데이터와 AI 문맥을 안전하게 조합합니다.

추천 사용 사례: 데스크톱 중심 운영, 장기 작업 흐름, 개인 로컬 관리.

Android App

이동 중에도 메모와 일정, 작업 상태를 유지하는 모바일 중심 옵션입니다.

  1. 1
    앱을 실행해 프로젝트와 작업 목록을 확인합니다.
  2. 2
    메모, 체크리스트, 일정 정보를 입력합니다.
  3. 3
    간단한 알림 및 리마인더를 사용해 다음 행동을 정리합니다.
  4. 4
    필요 시 로컬 백업 또는 사용자가 직접 시작한 수동 동기화를 수행합니다.

추천 사용 사례: 이동 중 작업 관리, 짧은 메모 기록, 빠른 우선순위 점검.

Web / PWA

브라우저에서 로컬 중심 데이터를 사용하도록 설계된 접근형 인터페이스입니다.

  1. 1
    브라우저로 앱에 접속합니다.
  2. 2
    IndexedDB 또는 브라우저 로컬 저장소를 기반으로 작업과 메모를 보관합니다.
  3. 3
    오프라인 상태에서도 핵심 작업 흐름을 유지합니다.
  4. 4
    필요한 경우 로컬 백업과 데이터를 복원합니다.

추천 사용 사례: 브라우저 기반 빠른 접근, 간단한 대시보드, 오프라인 사용 환경.

Browser Extension

브라우저 컨텍스트를 보조적으로 기록하는 경량 도구입니다.

  1. 1
    브라우저 확장을 설치하고 필요한 권한을 확인합니다.
  2. 2
    페이지에서 아이디어, 링크, 짧은 메모를 사용자 명시적 동작으로 저장합니다.
  3. 3
    저장된 내용은 로컬 본체 앱 또는 다음 단계에서 검토할 수 있습니다.
  4. 4
    민감 정보는 저장하지 않으며, 자동 수집을 금지합니다.

추천 사용 사례: 웹 페이지 보조 메모, 아이디어 수집, 빠른 링크 보관.

AI Model Workbench

실험 데이터와 모델 관련 정보를 로컬에서 안전하게 관리하는 워크벤치입니다.

  1. 1
    데이터셋과 실험 목표를 정리합니다.
  2. 2
    로컬 AI 환경에서 평가와 결과를 기록합니다.
  3. 3
    장기 결과를 메타데이터와 비교해 추적합니다.
  4. 4
    과금 또는 외부 전송이 필요할 때는 사용자가 직접 승인합니다.

추천 사용 사례: 로컬 실험 관리, 메타데이터 추적, 비용 제어가 중요한 실험 작업.
